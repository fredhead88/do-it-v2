# spec: Playbooks, tuning and API reference: fix the leftover misleading statements

## Goal

The seven listed docs change from carrying misleading or dead-end statements to carrying accurate, dated ones.

In plain English: a few leftover guides send readers to a dead end, to files that are not in the repository, or make old review findings look like live bugs; this spec fixes those and adds dated notes where a snapshot reads as current.

An audit of docs/playbooks, docs/tuning, docs/wiki and docs/amazon-api-reference.md against the repo, production data and live reads (2026-10-15) found the statements below misleading. `docs/wiki/*` was checked: seed and draft pages with no commands or paths, no change. This spec shares no file with `playbooks-and-tuning-stale-a`.

Evidence, by requirement:
